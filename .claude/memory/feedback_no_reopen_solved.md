已解決的問題不再報告給使用者。確認方法：看程式碼實際狀態，而非看分析/調查文件的標題或內容。

**Why:** 使用者在 2026-05-10 糾正：DC Pilot Bug 明明已解決，Claude 卻把 `dc_pilot_bug_report.md`（舊分析文件）誤讀為「尚未解決的待辦事項」重新報告，浪費時間且造成混亂。

**How to apply:**
- 看到 review/ 或 notes/ 資料夾下的分析文件，先查程式碼確認問題是否已修復，不要直接引用文件中的「尚未驗證」等舊狀態
- 記憶檔中標記「✅ 已解決」或「已修復」的項目，進度報告時直接略過，不再展開細節
- 報告進度時只列「待解決」和「進行中」的項目
