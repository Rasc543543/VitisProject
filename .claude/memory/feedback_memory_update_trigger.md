每次對話中，一旦得出**確定性結論**（設計決策、驗證結果、問題解決、方案確認等），立即：

1. 判斷哪些記憶檔與此結論相關
2. 若有需要更新的內容，直接更新，不等到對話結束才做
3. 在被更新的記憶檔內加入更新記錄（日期 + 更新內容摘要）

**尚未得出結論時（仍在討論、探索、比較方案中）→ 不更新記憶。**

**Why:** 使用者希望記憶即時反映已確定的狀態，避免下次對話讀到過時或不完整的記憶，導致重複分析或報告已解決的問題。

**How to apply:**
- 「確定性結論」的判斷標準：使用者確認方案、驗證通過、bug 修復確認、設計選定
- 不算結論的情況：仍在比較選項、討論可能性、分析問題原因但尚未確認
- 更新時在記憶檔末尾或對應段落加上：`（更新：YYYY-MM-DD，內容摘要）`
- 同步更新 MEMORY.md 的索引描述（若一行描述已過時）
- **更新後必須在當次回應中留一行紀錄**，格式：
  `（記憶更新：檔名.md → 更新內容摘要）`
  讓使用者不需要進記憶資料夾就能驗證更新是否正確執行。
