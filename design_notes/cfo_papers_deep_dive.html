1
Carrier Frequency Offset-Based OFDM Synchronization Technology
Classen & Meyr 兩階段同步方法的 Review 分析

核心架構：Capture + Tracking 雙模

Capture Mode（大掃描）
  • 估測 integer CFO + fractional CFO
  • 補償量 = integer + fractional 之和
  • 對應你的：啟動時 141-offset 掃描
Tracking Mode（trace mode）
  • 只估測並補償 fine CFO
  • 使用 pilot 的相位旋轉量計算
  • 對應你的：neighbor energy check

Tracking Mode 數學公式

ε̂_f = (1 / 2π·T_sub·D) · arg{ Σ(j=1 to L-1) Y_{l+D}[p, ε̂_acq] · Y_l*[p, ε̂_acq] · X_{l+D}*[p] · X_l[p] } 其中： Y = 接收到的頻域信號 X = 已知 pilot 符號（訓練序列） p = pilot subcarrier 索引 ε̂_acq = capture phase 取得的粗 CFO 估測值 D = 符號間距（用相鄰 pilot 之間的相位差）

Pilot 結構要求

每個 OFDM symbol 都要嵌入 pilot，才能做連續追蹤（your 273 pilots/frame 符合此要求）。Pilot 位置固定於特定 subcarrier index p，公式中對所有 j 個連續符號的 pilot 相關值加總。

缺失資訊（此為 review paper 的限制）

⚠ 切換觸發條件未指定：論文未說明何時從 tracking mode 回到 capture mode（你需要自己設計 neighbor energy check 觸發邏輯）
⚠ 計算複雜度未與 exhaustive search 比較
⚠ Pilot 數量未給出具體數字

對你的價值

✅ 學術引用依據：你的 CFO cache 設計（掃一次 → 只做 neighbor check）在學術上有名稱叫 "Classen capture+tracking two-mode"，可引用此論文作為方法論基礎。

A Novel Integer Frequency Offset Estimation Method for OFDM Based on Preamble
SAL Algorithm｜Adjacent Subcarrier Similarity｜絕對值取代平方

核心數學原理：鄰近 Subcarrier 相似性

/* 傳統做法（SAH）：最小化差值能量 */ Ĝ = argmin_g Σ_k |Z(k) - Z(k-1)|² 其中 Z(k) = Y(k) · X*(k-g)，Y=接收，X=preamble，g=候選 IFO /* SAL（低複雜度版）：改用絕對值之和 */ Ĝ = argmin_g Σ_k ( |Re(M(k))| + |Im(M(k))| ) 其中 M(k) = Z(k) - Z(k-1) /* 直覺解釋： g 正確時 → Z(k)≈1 → M(k)≈0 → |Re|+|Im| 最小 g 錯誤時 → Z(k) 隨機複數 → M(k) 大 → |Re|+|Im| 大 */

硬體優化關鍵：兩個省乘法器技巧

❌ 傳統方法（SAH）
energy = Re² + Im²
需要 2 個 multiplier per subcarrier

~38,493 次乘法
✅ SAL 方法
energy = |Re| + |Im|
只需 abs() = sign bit 操作
完全不需要 multiplier！
Conjugate mul → bit swap/invert
因為 preamble 值域限制在 {1, j, -1, -j}，X*(k-g) 的共軛乘法可以化簡成 real/imaginary 部分的交換或取反，無需真正的複數乘法器。

Decision Feedback Frequency Offset Estimator for Data-Pilot Multiplexed OFDM
兩步驟決策回饋｜消除 ICI Error Floor｜高 SNR 性能優化

兩步驟流程

Step 1：Coarse + 決策回饋
  • 用 scattered pilots 做粗 CFO 補償（Classen/Bai）

  • 解調 data symbols（決策回饋）

Error Floor 問題解釋

傳統 pilot-only tracking 問題： - 在高 SNR 時，殘餘 CFO 造成的 ICI 不可忽略 - 但 pilot 太稀疏，無法精確估計這個 residual CFO - 結果：BER 在高 SNR 不再下降 → error floor Decision Feedback 解法： - 先把 data symbols 解碼（反正 SNR 高，初步解碼準確） - 把解碼後的 data 當作已知符號 - 用 ALL subcarriers 做精細 CFO 估計 → residual CFO 準確到位

對你的價值

ℹ 你目前 BER=0，ZCU208 loopback CFO≈0，不存在 ICI error floor 問題。
未來部署到 RF 鏈路（USRP、不同 FPGA），若出現高 SNR BER floor，這是解法。暫時不需要實作。

LS 公式展開成 Shift-Add

/* 802.11a 的 4 個 pilot 位置：-21, -7, +7, +21 */ /* 原始 LS slope 公式（需要乘法器） */ λ = (-3θ(-21) - θ(-7) + θ(7) + 3θ(21)) / K ← K 不是 2 的次方 /* 近似展開為 3 個 2 的次方分母之和 */ λ ≈ X/128 - X/2048 - X/4096 其中 X = -3θ(-21) - θ(-7) + θ(7) + 3θ(21) /* 硬體實作 */ X/128 → X >> 7 (右移 7 位) X/2048 → X >> 11 (右移 11 位) X/4096 → X >> 12 (右移 12 位) 3θ = (θ << 1) + θ (shift-add，不用 multiplier)

Loop_CFO_Scan 能量計算優化

❌ 目前（需要 multiplier）
// 每個 offset × 每個 pilot int sq_i = ...; // pilot 乘積 real int sq_q = ...; // pilot 乘積 imag energy += sq_i * sq_i + sq_q * sq_q; // → HLS 推斷 2 個 DSP multiplier
✅ SAL 改法（只需 abs）
// 完全等價的 argmax 結果 int sq_i = ...; int sq_q = ...; energy += (sq_i < 0 ? -sq_i : sq_i) + (sq_q < 0 ? -sq_q : sq_q); // → 純加法，0 個 multiplier
✅ argmax 不受影響：L1 norm（|Re|+|Im|）和 L2 norm（Re²+Im²）對同一組數據的 argmax 結果相同，因為兩者都是正單調函數。
