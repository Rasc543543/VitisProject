1  問題背景

原版 ref_rx_packed 每幀執行 141 次 CFO offset 掃描，佔整個 IP 執行時間的 94%（428 µs / 幀）。


CFO（載波頻率偏移）本質是振盪器頻率差，幀間幾乎不變，每幀重掃是純冗餘計算。


掃描方式每幀計算量時間 @100 MHz佔比
原版（全掃）141 offset × 139 pilot~428 µs94%
新版 Locked（±5）11 offset × 139 pilot~33 µs7%

Static 變數（跨幀保存於 FPGA fabric）

static int  cfo_state  = 0;     // 上一幀最佳 offset
static bool cfo_locked = false;  // false=Unlocked, true=Locked

Locked 模式核心邏輯

for (int d = -CFO_TRACK_W; d <= CFO_TRACK_W; d++) {  // CFO_TRACK_W = 5
    int offset = cfo_state + d;
    if (offset < -CFO_RANGE || offset > CFO_RANGE) continue;
    // 計算 139 個 pilot 的能量和...
}
// boundary_hit：新 best 跑到視窗邊界 → 下一幀重掃
if (drift >= CFO_TRACK_W || drift <= -CFO_TRACK_W)
    cfo_locked = false;

只用 boundary_hit，不用 energy_drop 的原因： Pilot/Data 能量比僅 1.78×，channel fading 會讓 energy_drop 誤觸發； boundary_hit 直接偵測漂移速度，不依賴能量門檻，更可靠。

驗證公式

最大 Doppler shift (Hz) = f_carrier × v_radial_max / c = f_carrier × 7500 / 3×10⁸ Doppler 變化率 (Hz/s) ≈ 依軌道幾何，最差情況下： Δf/Δt ≈ 2 × f_carrier × v² / (c × h) （h = 衛星高度） 每幀漂移 (subcarrier) = Doppler 變化率 × frame_duration / subcarrier_spacing 若每幀漂移 ≤ 5 subcarrier → CFO_TRACK_W = 5 安全 若每幀漂移 > 5 subcarrier → 需加大 CFO_TRACK_W（代價：Locked 時間增加）
